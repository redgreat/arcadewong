# 03 · 判断与循环

游戏 = 「在什么情况下，做什么事」+「反复做」。这一章把这两件事讲完，就够写本仓库所有示例了。

---

## 3.1 `if / else`：做不做，看条件

**TypeScript**

```ts
if (score > 10) {
    game.over(true)
} else if (score > 5) {
    music.baDing.play()
} else {
    info.changeLifeBy(-1)
}
```

**静态 Python**

```python
if score > 10:
    game.over(True)
elif score > 5:
    music.ba_ding.play()
else:
    info.change_life_by(-1)
```

| | TS | Python |
| --- | --- | --- |
| 代码块 | `{ ... }` | **冒号 `:` + 缩进 4 空格** |
| 否则如果 | `else if` | `elif` |
| 相等 | `===` | `==` |
| 不等 | `!==` | `!=` |
| 并且 / 或者 | `&&` / `\|\|` | `and` / `or` |
| 取反 | `!` | `not` |
| 真 / 假 | `true` / `false` | `True` / `False` |

> **缩进就是语法**：Python 里少缩进一格，那行就不属于这个 `if` 了。从积木转过来最需要适应这一点。

### 条件里常用的比较

`>` `<` `>=` `<=` `==` `!=`，以及游戏里最常用的一条 —— **矩形碰撞**：

```ts
function hit(ax, ay, aw, ah, bx, by, bw, bh) {
    return ax < bx + bw && ax + aw > bx && ay < by + bh && ay + ah > by
}
```

```python
def hit(ax, ay, aw, ah, bx, by, bw, bh):
    return ax < bx + bw and ax + aw > bx and ay < by + bh and ay + ah > by
```

意思是「两个矩形在 x 方向重叠**并且**在 y 方向也重叠」。`06-legend-collection` 不用精灵系统，全靠这一行判碰撞。

## 3.2 三元表达式（一行里选一个值）

**TS**：`条件 ? A : B`　**Python**：`A if 条件 else B`

```ts
screen.printCenter("1 PIZZA", 40, cursor === 1 ? 5 : 1)   // 选中就黄色
```

```python
screen.print_center("1 PIZZA", 40, 5 if cursor == 1 else 1)
```

菜单高亮全靠这一句，比写四行 `if` 清爽得多。

## 3.3 循环：把同一件事做好多次

### 遍历数组（最常用）

```ts
for (const p of sprites.allOfKind(SpriteKind.Food)) {
    if (p.y > 128) p.destroy()
}
```

```python
for p in sprites.all_of_kind(SpriteKind.food):
    if p.y > 128:
        p.destroy()
```

### 按次数循环

```ts
for (let i = 0; i < 5; i++) {
    screen.printCenter(TOOLS[i], 24 + i * 18, 1)
}
```

```python
for i in range(5):
    screen.print_center(TOOLS[i], 24 + i * 18, 1)
```

`range(5)` 产生 0,1,2,3,4（**不包含 5**）。

### 条件循环

```ts
let i = 0
while (i < list.length) { i++ }
```

```python
i = 0
while i < len(list):
    i = i + 1
```

> 静态 Python **没有** `for i++`、`break`/`continue` 可用但要小心：在 `while` 里删除数组元素时，删掉后**不要**把下标 +1，否则会跳过一个元素。`06-legend-collection/main.py` 里大量用了这种「删了就 `continue`」的写法。

## 3.4 「每一帧」不需要自己写循环！

这是 MakeCode 最省心的地方：**引擎已经帮你转起来了**。

```ts
game.onUpdate(function () { /* 每帧：算逻辑 */ })
game.onShade(function () { /* 每帧：画画面 */ })
game.onUpdateInterval(800, function () { /* 每 800ms：生成东西 */ })
```

```python
def update():
    pass

def draw():
    pass

game.on_update(update)
game.on_shade(draw)
game.on_update_interval(800, spawn)
```

**千万不要**在 `onUpdate` 里写 `while(true)` —— 会把主循环卡死，机器直接黑屏。
需要「每隔一段时间做一次」，用 `onUpdateInterval` 或自己用 `control.millis()` 记上次时间。

## 3.5 状态机：同一个键，在不同情况下做不同的事

这是 `05-toolbox` 反应测试的核心套路，也是所有互动程序的通用骨架：

```ts
let state = 0   // 0 待开始 / 1 随机等待 / 2 变绿计时 / 3 显示结果
controller.A.onEvent(ControllerButtonEvent.Pressed, function () {
    if (state === 0) {
        state = 1
        waitUntil = game.runtime() + Math.randomRange(1000, 4000)
    } else if (state === 2) {
        result = game.runtime() - t0
        state = 3
    } else if (state === 3) {
        state = 0
    }
})
```

**给孩子讲**：红绿灯。同样是「按按钮」，在不同灯下含义完全不同；`state` 就是记录「现在是哪种灯」的那个数。
画图比讲术语有效：画 4 个圆圈写 0/1/2/3，再用箭头标出「按 A 从哪个圈走到哪个圈」。

## 3.6 本章最小可运行例子：按 A 让方块左右跳

**TypeScript**

```ts
let x = 20
let dir = 2
controller.A.onEvent(ControllerButtonEvent.Pressed, function () {
    dir = -dir                 // 方向反转
})
game.onUpdate(function () {
    x = x + dir
    if (x > 140 || x < 0) dir = -dir    // 撞墙反弹
})
game.onShade(function () {
    screen.fill(15)
    screen.fillRect(x, 50, 12, 12, 5)
    screen.printCenter("A = TURN", 96, 1)
})
```

**静态 Python**

```python
x = 20
dir = 2

def turn():
    global dir
    dir = -dir

def update():
    global x, dir
    x = x + dir
    if x > 140 or x < 0:
        dir = -dir

def draw():
    screen.fill(15)
    screen.fill_rect(x, 50, 12, 12, 5)
    screen.print_center("A = TURN", 96, 1)

controller.A.on_event(ControllerButtonEvent.PRESSED, turn)
game.on_update(update)
game.on_shade(draw)
```

这个 20 行例子把本章全串起来了：`if` 判断、`onUpdate` 算逻辑、`onShade` 画画面、事件改状态、Python 的 `global`。
可以让孩子把 `dir` 初值改成 5，或把反弹改成「从另一边穿出来」。

## 3.7 常见坑

| 现象 | 原因 |
| --- | --- |
| Python 缩进报奇怪的错 | 混用了空格和 Tab，或缩进少一格 |
| `if` 永远不成立 | TS 写成 `=`（赋值）而不是 `===`；Python 里 `==` 写成 `=` 直接语法错 |
| 机器卡死 / 黑屏 | 在 `onUpdate` 里写了死循环 |
| 遍历数组漏元素 | 删了第 i 个元素后还是 `i = i + 1` |
| 一秒响 30 次音效 | 判断条件每帧都成立，要配一个「已经响过」的状态变量 |
