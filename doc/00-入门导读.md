# 00 · 入门导读：只学这台机器用得到的那部分

这套文档**不是**完整的 TypeScript 或 Python 教程。它只覆盖「给 ELECFREAKS Retro Arcade（MakeCode Arcade / F4 / STM32F401）写游戏和小应用」真正会用到的知识。

- 用不上的一律不写：类、继承、模块打包、文件 IO、网络、异步、装饰器、标准库、类型体操……
- 每个知识点都配一段**能直接刷进这台机器**的小例子。
- 每段例子都同时给 **TypeScript** 和 **静态 Python** 两种写法，方便对照。

> 第一次来？先看带图的 [`硬件介绍.md`](硬件介绍.md) 认识机器，再回到这里按顺序学。

---

## 先记住这台机器的三条硬约束

| 约束 | 具体值 | 会怎么影响你写代码 |
| --- | --- | --- |
| 屏幕逻辑分辨率 | **160 × 120**，左上角 (0,0)，**y 向下变大** | 所有坐标都在这个范围里；向上飞要用**负速度** |
| 颜色 | **16 色调色板**，用 **0~15 的编号**，不是 RGB | `screen.fill(7)` 里的 7 就是 greens 那一格 |
| 内存 / 存储 | 96 KiB SRAM、512 KiB Flash（应用区约 448 KiB）、**无 SD 卡 / 无文件系统** | 精灵、子弹用完要 `destroy()`；一个 UF2 = 一个程序 |

另外两条「软件约束」最容易踩：

1. **绘制必须放 `game.onShade()` / `game.on_shade()`**，放 `onUpdate` 会被引擎清屏擦掉 → 全黑屏。见 [第 6 章](06-屏幕绘图与坐标.md)。
2. **Python 是「静态 Python」**，会先转译成 TypeScript 再编译成本机码，**不是 MicroPython**：不能 `import`、不能 `lambda`、空数组要写类型标注。见 [第 9 章](09-Python特别注意事项.md)。

## 推荐的两条路线

### 路线 A：教孩子（图形化 → 文本）

1. 官网 <https://arcade.makecode.com/?lang=zh-cn> → 教程 → **Chase the Pizza**，纯积木搭一遍。
2. 打开 `projects/01-catch-the-pizza/README.md` 的「给孩子讲的教案」，按任务表改数字。
3. 右上角从积木切到 **JavaScript**，看同一段程序长什么样（读 [02][04][07] 章）。
4. 想试 Python 就切到 **Python**，对照 `main.py`（读 [09][10] 章）。

> **不要**一上来就让孩子读手写的大项目。手写代码反编译成积木时会出现灰色代码块，具体原因见 `projects/README.md`。

### 路线 B：成人 / 大孩子快速上手

1. [01 章] 装好工具、跑通一次编译烧录。
2. [02→04→07 章] 按顺序读，每章的例子刷进机器看一眼。
3. 照 `projects/01-catch-the-pizza` 改出自己的第一个游戏。
4. [06][08] 学会画屏和多游戏菜单 → 看 `04`、`05`、`06` 的架构。

## 编译 / 烧录速查（先看 [01 章](01-认识这台机器与开发环境.md) 再动手）

```bash
# 在本仓库根目录，任选一个项目的任一语言版本编译
bash tools/build-lang.sh 01-catch-the-pizza ts firmware/my-game.uf2
bash tools/build-lang.sh 01-catch-the-pizza py firmware/my-game-py.uf2
```

```powershell
# 按一下机身复位键 → 出现 ARCADE-F4 盘 → 自动写入
powershell -ExecutionPolicy Bypass -File tools\flash.ps1 -Game 1
```
