# 05 · 数组与字符串（子弹、敌人、地图都靠它）

只要游戏里出现「很多个同样的东西」——一堆子弹、一排敌人、几张地图——就会用到数组。本章只讲这台机器上真正用得到的部分。

---

## 5.1 创建数组

**TypeScript**

```ts
const TOOLS = ["CALC", "DICE", "TORCH"]     // 文字数组
const xs: number[] = [10, 9, 8]             // 数字数组
const bx: number[] = []                     // 空数组，也能用
```

**静态 Python**

```python
TOOLS = ["CALC", "DICE", "TORCH"]
xs = [10, 9, 8]
bx: List[number] = []        # ⚠️ 空数组必须写类型标注
```

> **`List[number] = []` 是静态 Python 特有的一条硬规矩。**
> 写 `bx = []` 会转译成 `let bx: any[] = []`，编译报 `implicitly has type 'any[]'`。
> 有初始元素时（`xs = [10, 9, 8]`）能自动推断，不用标注。

## 5.2 读写、长度、遍历

| 操作 | TS | 静态 Python |
| --- | --- | --- |
| 取第 i 个 | `a[i]` | `a[i]`（相同，下标从 **0** 开始） |
| 改第 i 个 | `a[i] = 5` | `a[i] = 5` |
| 长度 | `a.length` | `len(a)` |
| 加到最后 | `a.push(v)` | `a.append(v)` |
| 插到开头 | `a.insertAt(0, v)` | `a.insert_at(0, v)` |
| 删第 i 个 | `a.removeAt(i)` | `a.remove_at(i)` |
| 删末尾 | `a.pop()` | `a.pop()`（**不能带参数**） |
| 遍历 | `for (const x of a)` | `for x in a` |
| 按次数遍历 | `for (let i=0; i<a.length; i++)` | `for i in range(len(a))` |

⚠️ 静态 Python **不支持 `pop(0)`**（报 `too many arguments in call to 'Array.pop'`），要删开头请用 `remove_at(0)`。
⚠️ 不支持切片 `a[1:]`、不支持列表推导式、不支持 `lambda`。

## 5.3 遍历时删除：最容易出的 bug

```python
i = 0
while i < len(bx):
    bx[i] = bx[i] + 3
    if bx[i] > 170:
        bx.remove_at(i)      # 删掉后，下一个元素挪到了 i 的位置
        continue             # ✅ 不要 i = i + 1，否则会跳过一个
    i = i + 1
```

对应的 TS：

```ts
for (let i = bx.length - 1; i >= 0; i--) {   // 倒着遍历也很稳
    bx[i] += 3
    if (bx[i] > 170) bx.removeAt(i)
}
```

`06-legend-collection` 里子弹、敌人、爆炸粒子全靠这个模式管理。

## 5.4 「平行数组」：不用对象也能管一堆实体

静态 TS / Python 里对象数组又贵又麻烦。本仓库的大项目统一用**几个等长数组 + 同一个下标**表示一组东西：

```ts
let bx: number[] = []     // 每颗子弹的 x
let by: number[] = []     // 每颗子弹的 y
let bvx: number[] = []    // 每颗子弹的 x 速度
let bvy: number[] = []    // 每颗子弹的 y 速度
// 第 i 颗子弹 = (bx[i], by[i], bvx[i], bvy[i])
```

```python
bx: List[number] = []
by: List[number] = []
bvx: List[number] = []
bvy: List[number] = []

def add_bullet(x, y, vx, vy):
    bx.append(x); by.append(y); bvx.append(vx); bvy.append(vy)

def del_bullet(i):
    bx.remove_at(i); by.remove_at(i); bvx.remove_at(i); bvy.remove_at(i)
```

**四条数组必须同步增删**，漏一条就会错位（子弹位置对不上速度）。讲的时候可以画一张表格，一行是一颗子弹，一列是一个属性 —— 孩子立刻就懂了。

贪吃蛇则用两个数组存身体：`xs = [10, 9, 8]` / `ys = [6, 6, 6]`，头在下标 0；走一步就是「头插新坐标 + 删掉尾巴」。

## 5.5 字符串：菜单文字、地图、像素画

### 拼接与转换

```ts
"SC:" + score
str(i + 1) + " " + TOOLS[i]
```

```python
"SC:" + str(score)
str(i + 1) + " " + TOOLS[i]      # 必须 str()
```

### 字符地图（关卡数据的最佳载体）

`06-legend-collection/tanks.ts` 里的坦克地图就是一组等长字符串：

```ts
const MAPS = [
    "................",
    "..BB..SS..BB....",
    "....GG....GG....",
    ".......X........",
]
```

`.` 空地 / `B` 砖 / `S` 钢 / `W` 水 / `G` 草 / `X` 基地。
静态 Python 里可以直接用 `MAP[y][x]` 取某个字符（已实测可用）：

```python
MAP = ["................", "..BB..SS..BB...."]
ch = MAP[1][2]        # "B"
```

**好处**：改关卡不用改代码，改一行字符就行 —— 非常适合让孩子「设计自己的关卡」。
⚠️ **每行长度必须一致**，否则下标会越界。本仓库编译前会跑脚本校验行宽。

### 像素画

```ts
const hero = sprites.create(img`
    . . 4 4 . .
    . 4 4 4 4 .
    . . f f . .
`, SpriteKind.Player)
```

```python
hero = sprites.create(img("""
. . 4 4 . .
. 4 4 4 4 .
. . f f . .
"""), SpriteKind.player)
```

数字是调色板编号，`.` / `f` 是透明。TS 用反引号，Python 用三引号字符串。

## 5.6 本章最小可运行例子：一排会移动的点

**TypeScript**

```ts
const xs: number[] = [10, 40, 70, 100, 130]
game.onUpdate(function () {
    for (let i = 0; i < xs.length; i++) {
        xs[i] = xs[i] + 1
        if (xs[i] > 158) xs[i] = 0
    }
})
game.onShade(function () {
    screen.fill(15)
    for (const x of xs) screen.fillRect(x, 60, 4, 4, 5)
})
```

**静态 Python**

```python
xs = [10, 40, 70, 100, 130]

def update():
    i = 0
    while i < len(xs):
        xs[i] = xs[i] + 1
        if xs[i] > 158:
            xs[i] = 0
        i = i + 1

def draw():
    screen.fill(15)
    for x in xs:
        screen.fill_rect(x, 60, 4, 4, 5)

game.on_update(update)
game.on_shade(draw)
```

注意 `update()` 里**没有** `global xs`：这里改的是 `xs[i]`（数组里的元素），不是给 `xs` 本身重新赋值，所以不需要 `global`。这个区别值得单独讲一次。

## 5.7 常见坑

| 现象 | 原因 |
| --- | --- |
| `implicitly has type 'any[]'` | Python 空数组没写 `a: List[number] = []` |
| `too many arguments in call to 'Array.pop'` | 用了 `pop(0)`，改 `remove_at(0)` |
| 下标越界 / 画面乱飞 | 平行数组增删不同步；或地图每行长度不一致 |
| 遍历时漏掉元素 | 删除后仍把 `i` 加了 1 |
| 数组越来越长、机器变卡 | 飞出屏幕的对象没删（见 [第 7 章](07-精灵碰撞与计分.md) 的回收） |
