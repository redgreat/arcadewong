# 01 · 认识这台机器与开发环境

本章只讲**动手之前必须知道**的东西：机器是什么、按键叫什么、代码怎么变成固件。

---

## 1.1 硬件（会影响写代码的就这几点）

| 项目 | 值 | 写代码时的含义 |
| --- | --- | --- |
| 主控 | STM32F401（MakeCode Arcade 里的 **F4** 硬件） | `mkc.json` 里写 `hwVariant: "stm32f401"` |
| 屏幕 | 2.4" 彩屏，**逻辑分辨率 160×120** | 坐标范围 x: 0~159、y: 0~119；引擎内部缩放，别按 320×240 算 |
| 颜色 | **16 色**，用编号 0~15 | 不是 `#RRGGBB`，是 `screen.fill(7)` 这种 |
| 按键 | 方向键 ↑↓←→ + **A** + **B**（+ 菜单/复位） | `controller.up` / `A` / `B` … |
| 内存 | 96 KiB SRAM | 精灵、子弹用完要销毁 |
| Flash | 512 KiB，应用区约 **448 KiB**（`0x08010000`~`0x08080000`） | 一个 UF2 编译出来别超过这个数 |
| 存储 | **没有 SD 卡、没有文件系统** | 「加载好多 ROM」做不到；只能 `settings` 存几个数字 |
| 其它 | 蜂鸣器、陀螺仪、光敏、震动 | `music.*`、传感器扩展块 |
| 下载 | 按复位键 → 变成 `ARCADE-F4` U 盘，拖 `.uf2` 进去 | 免驱，Windows 自带驱动 |

> 想看带图的完整硬件介绍（机身按键、内存地图、调色板、能跑什么）见 [`硬件介绍.md`](硬件介绍.md)。

### 16 色调色板（编号 → 大致颜色）

| 编号 | 颜色 | 编号 | 颜色 |
| --- | --- | --- | --- |
| 0 | 透明 | 8 | 蓝 |
| 1 | 白 | 9 | 青 |
| 2 | 红 | 10 | 紫 |
| 3 | 粉 | 11 | 浅蓝 / 灰蓝 |
| 4 | 橙 | 12 | 棕 |
| 5 | 黄 | 13 | 深红 |
| 6 | 青绿 | 14 | 深蓝 |
| 7 | 绿 | 15 | 黑 |

**注意**：`15` 是黑、`1` 是白。像素画里的 `f` 表示透明（不是颜色 15）。

### 坐标系

```
(0,0) ──────────→ x 变大（最右 159）
  │
  │     屏幕 160 × 120
  ↓
y 变大（最下 119）
```

- 和数学课的坐标系**相反**：往下 y 变大。
- 所以「向上飞」的速度要写**负数**：`createProjectileFromSide(img, 0, -130)`。
- 精灵的 `x / y` 默认是**中心点**，不是左上角；`screen.fillRect(x,y,w,h,c)` 的 `x/y` 是**左上角**。

## 1.2 三种开发方式

| 方式 | 怎么用 | 适合 |
| --- | --- | --- |
| **网页版** <https://arcade.makecode.com> | 积木 / JavaScript / Python 一键切换，自带模拟器，可「安装为应用」离线用 | **教孩子首选** |
| **VS Code + 官方扩展 "Microsoft MakeCode Arcade"** | 纯 TypeScript，智能提示、像素画编辑器、内置模拟器、一键编译 UF2 | 想用桌面 IDE |
| **命令行 `mkc`**（`npm i -g makecode`） | 不开浏览器：`mkc build` 出 UF2、`mkc serve` 起本地模拟器 | 批量编译 / Git 管理 |

网页版下载到真机：左下角「…」→ 选硬件 **F4** → 点「下载」得到 `.uf2` → 拖进 `ARCADE` 盘。
官方说明：<https://wiki.elecfreaks.com/retroarcade/program-download-method>

> 主控虽是 STM32F401，理论上能写 Arduino/C++，但会丢掉积木、模拟器和全部教程，**入门不建议**。

## 1.3 一个项目的目录长什么样

```
projects/01-catch-the-pizza/
  README.md     讲解 + 儿童教案
  main.ts       TypeScript 版
  main.py       Python 版
  pxt.json      MakeCode 项目清单（决定编译哪个文件）
  mkc.json      命令行编译设置（硬件变体）
```

### `pxt.json` 关键字段

```json
{
  "name": "catch-the-pizza",
  "files": ["main.ts"],              // ← 决定编译入口
  "supportedTargets": ["arcade"],
  "dependencies": { "device": "*" }
}
```

**Python 项目必须多一行**：

```json
"preferredEditor": "pyprj"
```

缺了它，命令行 `mkc build` 会**静默忽略 `main.py`、编出空壳固件却照样报 Build OK**，真机就是黑屏。见 [第 9 章](09-Python特别注意事项.md)。

### `mkc.json`

```json
{
  "targetWebsite": "https://arcade.makecode.com/",
  "hwVariant": "stm32f401",
  "links": {}
}
```

`hwVariant: "stm32f401"` 就是网页版里选的 **F4**。不写会编译成默认的模拟器目标，刷进这台机器不能用。

## 1.4 把代码变成游戏（完整四步）

```bash
# ① 编译（在仓库根目录；脚本会自动生成临时工程、校验 UF2 头）
bash tools/build-lang.sh 01-catch-the-pizza ts firmware/my-game.uf2
bash tools/build-lang.sh 01-catch-the-pizza py firmware/my-game-py.uf2
```

```powershell
# ② 用数据线连上机器，按一下机身「复位」键
#    屏幕上出现下载界面，电脑多出一个名为 ARCADE-F4 的 U 盘（例 F:）

# ③ 拖入 UF2（或用脚本自动等待并写入）
powershell -ExecutionPolicy Bypass -File tools\flash.ps1 -Game 1
```

④ 机器自动重启，游戏开始跑。**一次只能装一个 UF2**，拖第二个会整体覆盖第一个；想「装好多游戏」请看 [第 8 章](08-状态机与存档.md)。

### 为什么 Python 版要两步编译

MakeCode 的 Python 是**静态 Python**：

```
main.py  ──mkc build -j──▶ built/main.ts ──mkc build──▶ binary.uf2
          （转译成 TypeScript）            （编译成 STM32F401 本机码）
```

`mkc build` 直接编 `pyprj` 项目会报 `no magic`（mkc 的已知限制）。
`tools/build-lang.sh` 已经把这两步包好了，直接用即可。

## 1.5 校验一个 UF2 是不是给这台机器的

```python
import struct
d = open("firmware/xxx.uf2", "rb").read()
magic  = struct.unpack_from("<I", d, 0)[0]   # 必须是 0x0A324655
family = struct.unpack_from("<I", d, 28)[0]  # 必须是 0x57755A57（STM32F401 / F4）
```

`tools/build-lang.sh` 每次编译结束都会自动做这个校验。family 不对 = 刷进去起不来。

## 1.6 驱动要不要装？

**不用。** 这台机器是「免驱 UF2 + WebUSB」设备：

- 插上后 Windows 自动把 `USB\VID_0483&PID_5799` 的接口 0 装成 WinUSB（网页版一键下载走它）。
- 设备管理器里带感叹号的 `Arcade (app)` 是**接口 1**，刷机用不到，不影响编程。
- 按复位键后变成 `ARCADE-F4` U 盘，用的是 Windows 自带驱动。

想消掉那个感叹号，双击 `tools/install-driver.cmd`、UAC 点「是」即可（只绑定系统自带 WinUSB）。

## 1.7 本章最小可运行例子

**TypeScript**

```ts
scene.setBackgroundColor(11)
game.splash("HELLO ARCADE")
game.onShade(function () {
    screen.fill(11)
    screen.printCenter("HELLO!", 40, 5)
    screen.printCenter("160 x 120", 62, 1)
})
```

**静态 Python**

```python
scene.set_background_color(11)
game.splash("HELLO ARCADE")

def draw():
    screen.fill(11)
    screen.print_center("HELLO!", 40, 5)
    screen.print_center("160 x 120", 62, 1)

game.on_shade(draw)
```

把任一段存成 `main.ts` / `main.py`，用 `tools/build-lang.sh` 编译刷入，屏幕上就会出现白字蓝底的两行字。
**试着把 `onShade` 改成 `onUpdate`** —— 会变成纯黑屏，这就是 [第 6 章](06-屏幕绘图与坐标.md) 要讲的事。

## 1.8 常见坑

| 现象 | 原因 |
| --- | --- |
| 拖 UF2 没反应 | 用了纯充电线；或没按复位键 |
| 刷完黑屏 | 绘制写在 `onUpdate`；或 Python 项目缺 `preferredEditor` 编出空壳 |
| 中文变方块 | 默认字库只有 ASCII，界面用英文 |
| 编译出的 UF2 刷不进 | `mkc.json` 缺 `hwVariant: "stm32f401"` |
| 玩久了越来越卡 | 精灵 / 子弹没 `destroy()` |
