# 04 · 函数与事件（回调）

MakeCode 程序没有 `main()`，也没有自己写的主循环。**你把一段段代码「挂」到事件上，引擎到点就来调用它。** 理解这一点，就理解了一半。

---

## 4.1 函数：给一段代码起个名字

**TypeScript**

```ts
function sayHi() {
    game.splash("HELLO")
}
sayHi()        // 调用：名字 + 括号
```

**静态 Python**

```python
def say_hi():
    game.splash("HELLO")

say_hi()       # 调用：名字 + 括号
```

带参数与返回值：

```ts
function clamp(v: number, a: number, b: number): number {
    if (v < a) return a
    if (v > b) return b
    return v
}
```

```python
def clamp(v, a, b):
    if v < a:
        return a
    if v > b:
        return b
    return v
```

> 静态 Python 里**类型标注通常可省略**（编译器推断），但空数组必须写 `a: List[number] = []`。

## 4.2 事件：把函数「挂」上去

```ts
controller.A.onEvent(ControllerButtonEvent.Pressed, function () {
    // 按 A 时执行
})
game.onUpdateInterval(800, function () {
    // 每 800 毫秒执行
})
game.onUpdate(function () {
    // 每一帧执行（逻辑）
})
game.onShade(function () {
    // 每一帧执行（绘制，渲染之后）
})
```

**静态 Python 必须给每个回调起名字**（不支持 `lambda`，也不能把 `def` 塞进参数里）：

```python
def on_a():
    pass

def on_spawn():
    pass

def update():
    pass

def draw():
    pass

controller.A.on_event(ControllerButtonEvent.PRESSED, on_a)
game.on_update_interval(800, on_spawn)
game.on_update(update)
game.on_shade(draw)
```

### ⚠️ 传函数名，**不要带括号**

```python
game.on_shade(draw)      # ✅ 注册：「每帧去叫 draw」
game.on_shade(draw())    # ❌ 立刻执行一次，然后把返回值(None)注册进去
```

这是 Python 入门最经典的一个错。给孩子讲：「把写着任务的小纸条交给老师」vs「现在就把任务做完」。

## 4.3 四种常用事件，分别什么时候用

| 事件 | TS | Python | 用途 |
| --- | --- | --- | --- |
| 按键**按下瞬间** | `controller.A.onEvent(ControllerButtonEvent.Pressed, fn)` | `controller.A.on_event(ControllerButtonEvent.PRESSED, fn)` | 发射、跳跃、确认；按一次只触发一次 |
| 按键**持续按住** | `controller.left.isPressed()` | `controller.left.is_pressed()` | 移动；要放在 `onUpdate` 里每帧读 |
| **每帧逻辑** | `game.onUpdate(fn)` | `game.on_update(fn)` | 重力、移动、碰撞计算 |
| **每帧绘制** | `game.onShade(fn)` | `game.on_shade(fn)` | 所有 `screen.xxx` |
| **定时** | `game.onUpdateInterval(ms, fn)` | `game.on_update_interval(ms, fn)` | 生成敌人 / 掉落物 |
| **碰撞** | `sprites.onOverlap(kindA, kindB, fn)` | `sprites.on_overlap(kindA, kindB, fn)` | 见 [第 7 章](07-精灵碰撞与计分.md) |

> `onPaint` 也存在，但 `onShade` 更靠后（在 HUD 之后），画自己的界面更稳。本仓库一律用 `onShade`。

### 为什么绘制必须用 `onShade`

```
game.onUpdate（算逻辑）
    ↓
scene.render() → background.draw() → screen.fill(背景色)   ← 全屏擦除
    ↓
精灵 / HUD → onPaint → onShade
    ↓
送到屏幕
```

写在 `onUpdate` 里的 `screen.fill()` 画完立刻被擦掉 → **纯黑屏**。本仓库三个固件曾因此返工，原理与实测见 [第 6 章](06-屏幕绘图与坐标.md)。

## 4.4 回调的参数：谁是谁

碰撞回调会给两个精灵：

```ts
sprites.onOverlap(SpriteKind.Player, SpriteKind.Food, function (sprite, otherSprite) {
    // sprite      = 声明里写在前面的那类（Player）
    // otherSprite = 写在后面的那类（Food）
    otherSprite.destroy()
    info.changeScoreBy(1)
})
```

```python
def on_catch(sprite, otherSprite):
    otherSprite.destroy()
    info.change_score_by(1)

sprites.on_overlap(SpriteKind.player, SpriteKind.food, on_catch)
```

参数顺序由 `onOverlap` 里两个 `SpriteKind` 的顺序决定，别搞反。

## 4.5 闭包：函数「记住」外面的变量

```ts
function startDice() {
    let n = 0
    controller.A.onEvent(ControllerButtonEvent.Pressed, function () {
        n = n + 1          // TS：直接改，没问题
    })
    game.onShade(function () {
        screen.printCenter("" + n, 52, 5)
    })
}
```

静态 Python 里，嵌套函数给外层变量赋值要写 **`nonlocal`**：

```python
def start_dice():
    n = 0
    def roll():
        nonlocal n
        n = n + 1
    def draw():
        screen.print_center(str(n), 52, 5)
    controller.A.on_event(ControllerButtonEvent.PRESSED, roll)
    game.on_shade(draw)
start_dice()
```

| 层级 | Python 关键字 |
| --- | --- |
| 改**模块级**变量（写在文件最外层） | `global x, y` |
| 改**外层函数**的变量 | `nonlocal x, y` |
| 只读不改 | 什么都不用写 |

> 另一种写法：把状态放进**单元素列表** `n = [0]`，改 `n[0] = n[0] + 1` 就不需要 `nonlocal`。`05-toolbox/main.py` 用的就是这个办法，变量一多时更省事。

## 4.6 一个键、两种用途

```python
def key_a_both():
    if over or win:
        start_game(2)     # 结束时：重开
    else:
        jump()            # 平时：跳跃

controller.A.on_event(ControllerButtonEvent.PRESSED, key_a_both)
```

**别注册两次**（一次 `jump` 一次「重开」），否则两个回调都会触发，出现「结束时还跳了一下」这类怪现象。
`06-legend-collection/main.py` 里就是这么处理的。

### 按键不够怎么办：长按

```ts
let bHold = 0
game.onUpdate(function () {
    if (controller.B.isPressed()) {
        if (bHold === 0) bHold = control.millis()
        if (control.millis() - bHold >= 1200) toMenu()   // 长按 1.2 秒
    } else bHold = 0
})
```

短按留给游戏内操作，长按回菜单，再画一条进度条提示。`06-legend-collection` 的完整实现见 `main.ts` 的 `G.tickQuit()`。

## 4.7 音效别阻塞主循环

```ts
// ❌ 会 pause() 卡住游戏
music.playTone(440, 100)

// ✅ 后台播放（本仓库六个大游戏统一这么写）
music.tonePlayable(440, 100).play(music.PlaybackMode.InBackground)
```

```python
music.tone_playable(440, 100).play(music.PlaybackMode.IN_BACKGROUND)
```

另外像 `game.splash()` 也是**阻塞**的（等按键才继续），别放进 `onUpdate`。
爆炸时可能一帧响几十次，记得加限流：

```ts
if (control.millis() - lastBeep < 55) return
```

## 4.8 本章最小可运行例子：按 A 计数

**TypeScript**

```ts
let count = 0
controller.A.onEvent(ControllerButtonEvent.Pressed, function () { count++ })
game.onShade(function () {
    screen.fill(15)
    screen.printCenter("A PRESSED", 30, 5)
    screen.printCenter("" + count, 56, 2)
})
```

**静态 Python**

```python
count = 0

def on_a():
    global count
    count = count + 1

def draw():
    screen.fill(15)
    screen.print_center("A PRESSED", 30, 5)
    screen.print_center(str(count), 56, 2)

controller.A.on_event(ControllerButtonEvent.PRESSED, on_a)
game.on_shade(draw)
```

把 `on_a` 改成 `on_a()` 试试，观察「开机就变成 1、之后按键没反应」——比讲十遍印象深。
