# 02 · 变量、数字、随机数、文字

写游戏 90% 的时间都在跟「数」打交道：速度、坐标、分数、颜色编号、时间。本章是最短也最有用的一章。

---

## 2.1 变量：给一个数起名字

**TypeScript**

```ts
const PLAYER_SPEED = 110   // 不再改变 → const
let score = 0              // 游戏中会变 → let
score = score + 1
```

**静态 Python**

```python
PLAYER_SPEED = 110         # 约定全大写表示「不要改」，但语言本身不强制
score = 0                  # 直接赋值即可，没有 let / const
score = score + 1
```

| 规则 | TS | Python |
| --- | --- | --- |
| 声明 | `const` / `let` | 直接写 `名字 = 值` |
| 改不改 | `const` 真的不能改 | 靠命名约定（全大写） |
| 类型 | `let n: number = 0`（通常可省略） | 由第一次赋值推断，**之后不能换类型** |
| 大小写 | 敏感 | 敏感 |

> **静态 Python 的类型是「定下来就不变」的**：`n = 0` 之后不能 `n = "abc"`。
> 空数组必须写 `a: List[number] = []`，否则转译后是 `any[]` 会编译报错（见 [第 9 章](09-Python特别注意事项.md)）。

## 2.2 算术与取余

```ts
let a = 7, b = 2
a + b      // 9
a - b      // 5
a * b      // 14
a / b      // 3.5（MakeCode 的 number 不区分整数小数）
Math.floor(a / b)  // 3  取整
a % b      // 1   取余
```

Python 写法几乎一样：`Math.floor(a / b)`、`a % b` 都能用。
⚠️ Python 的 `//` 整除在静态 Python 里**不保证可用**，一律用 `Math.floor(a / b)`。

**`%` 的杀手级用途：转圈圈**

```ts
let op = 0
controller.A.onEvent(ControllerButtonEvent.Pressed, function () {
    op = (op + 1) % 4       // 0 → 1 → 2 → 3 → 0 → ...
})
```

`05-toolbox` 的计算器就是用它循环切换 `+ - * /`；菜单光标上下循环、手电筒换色也是这个套路。

## 2.3 随机数：让每局都不一样

**TypeScript**：`Math.randomRange(最小, 最大)`（**两端都包含**）

```ts
const x = Math.randomRange(12, 148)      // 随机横坐标
const n = Math.randomRange(1, 6)         // 骰子
```

**静态 Python**：内置 `randint(最小, 最大)`

```python
x = randint(12, 148)
n = randint(1, 6)
```

⚠️ **不要写 `import random`**。静态 Python 不支持 import，`randint` 是内置的。
`Math.min(a,b)` / `Math.max(a,b)` / `abs(x)` / `clamp` 两种语言都能用。

## 2.4 文字（字符串）与拼接

```ts
"SC:" + score              // 数字会自动转成文字（TS 里 "" + n 最稳）
game.splash("SCORE", "" + score)
```

```python
"SC:" + str(score)         # Python 必须用 str() 显式转
game.splash("SCORE", str(score))
```

| | TS | Python |
| --- | --- | --- |
| 拼接 | `+`（数字会自动转） | `+`（**必须 `str()`**） |
| 引号 | `"..."` 或 `'...'` | 同 |
| 多行像素画 | `` img`...` `` | `img("""...""")` |

⚠️ **界面文字请用英文**：这台机器默认字库只有 ASCII，中文会显示成方块。要中文得自绘点阵字库，非常占空间。

## 2.5 颜色编号（这台机器特有）

颜色不是 RGB，是 **0~15 的编号**：

```ts
screen.fill(15)                       // 黑底
screen.fillRect(10, 10, 20, 8, 2)    // 红色方块
screen.printCenter("HI", 40, 5)      // 黄色字
```

```python
screen.fill(15)
screen.fill_rect(10, 10, 20, 8, 2)
screen.print_center("HI", 40, 5)
```

像素画里每格是一个字符，数字/`a`~`f` 是调色板编号，`.` 或 `f` 是透明：

```ts
const hero = sprites.create(img`
    . . 4 4 4 4 . .
    . 4 4 4 4 4 4 .
    . . f f f f . .
`, SpriteKind.Player)
```

**给孩子最好的第一个任务**：把像素画里的 `4` 改成 `2`，角色立刻从橙变红。零风险、立刻见效。

## 2.6 「旋钮」约定（本仓库所有项目通用）

把**会影响手感的数字**全部集中放在文件最开头，起一个全大写的名字：

```ts
// ================== 可以随便改的旋钮 ==================
const PLAYER_SPEED = 110
const FALL_SPEED = 70
const SPAWN_MS = 800
const START_LIVES = 3
// ====================================================
```

```python
# ================== 可以随便改的旋钮 ==================
PLAYER_SPEED = 110
FALL_SPEED = 70
SPAWN_MS = 800
START_LIVES = 3
# ====================================================
```

**为什么**：程序长到 100 行以后，孩子再去找 `70` 藏在哪个 `createProjectileFromSide(...)` 里就很难了。
约定「先改数字 → 再改逻辑 → 最后自己写」，是这套示例项目最重要的教学设计。

## 2.7 时间：毫秒

设备里时间单位几乎都是**毫秒**（1 秒 = 1000 毫秒）：

| API | 作用 |
| --- | --- |
| `game.onUpdateInterval(800, fn)` / `game.on_update_interval(800, fn)` | 每 800 ms 自动跑一次 |
| `game.runtime()` | 开机到现在的毫秒数，**一直变大，停不下来** |
| `control.millis()` | 同上，更底层的写法 |
| `Math.floor(ms / 1000)` | 换成秒 |

`py-03-stopwatch` 把「绝对时间 → 秒表」讲得很细：秒表 = 记下开始时刻，然后每帧算「现在 − 开始」。

## 2.8 本章最小可运行例子：随机变色方块

**TypeScript**

```ts
let n = 0
controller.A.onEvent(ControllerButtonEvent.Pressed, function () {
    n = Math.randomRange(1, 14)
})
game.onShade(function () {
    screen.fill(15)
    screen.fillRect(60, 40, 40, 40, n)
    screen.printCenter("COLOR " + n, 96, 1)
})
```

**静态 Python**

```python
n = 1

def roll():
    global n
    n = randint(1, 14)

def draw():
    screen.fill(15)
    screen.fill_rect(60, 40, 40, 40, n)
    screen.print_center("COLOR " + str(n), 96, 1)

controller.A.on_event(ControllerButtonEvent.PRESSED, roll)
game.on_shade(draw)
```

按 A 随机换一个颜色，顺便把 0~15 号色认一遍。
注意 Python 版 `roll()` 里的 `global n` —— 见 [第 9 章](09-Python特别注意事项.md)。
