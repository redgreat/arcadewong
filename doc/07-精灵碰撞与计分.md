# 07 · 精灵、碰撞、计分与回收

`01 / 02 / 03` 三个入门游戏全建立在这一章之上。**精灵（Sprite）** 是 MakeCode 帮你管好的「会动的小图片」。

---

## 7.1 造一个精灵

**TypeScript**

```ts
const player = sprites.create(img`
    . . 4 4 4 4 . .
    . 4 4 4 4 4 4 .
    . . f f f f . .
`, SpriteKind.Player)
player.x = 80
player.y = 108
```

**静态 Python**

```python
hero = sprites.create(img("""
. . 4 4 4 4 . .
. 4 4 4 4 4 4 .
. . f f f f . .
"""), SpriteKind.player)
hero.x = 80
hero.y = 108
```

| 要点 | 说明 |
| --- | --- |
| `img` | 像素画，数字是 0~15 调色板编号，`.` / `f` 透明 |
| `SpriteKind` | 给精灵贴的**类别标签**：`Player / Food / Enemy / Projectile` 等 |
| `x / y` | **中心点**坐标；屏幕 160×120 |
| 变量名 | Python 里**别用 `player`**（与系统预设名冲突），用 `hero` / `ship` |

### 常用精灵方法

| 作用 | TS | Python |
| --- | --- | --- |
| 限制在屏内 | `.setStayInScreen(true)` | `.set_stay_in_screen(True)` |
| 方向键控制 | `controller.moveSprite(s, 100, 0)` | `controller.move_sprite(s, 100, 0)` |
| 改类别 | `.setKind(SpriteKind.Enemy)` | `.set_kind(SpriteKind.enemy)` |
| 设速度 | `.vx = 50` / `.vy = -80` | 同 |
| 设加速度 | `.ax = 0` / `.ay = 230` | 同 |
| 隐身 | `.setFlag(SpriteFlag.Invisible, true)` | `.set_flag(SpriteFlag.INVISIBLE, True)` |
| 销毁 | `.destroy()` | `.destroy()` |
| 找同类 | `sprites.allOfKind(SpriteKind.Food)` | `sprites.all_of_kind(SpriteKind.food)` |

## 7.2 会自己飞的「投射物」

```ts
// 从屏幕边缘某个方向飞进来：createProjectileFromSide(图片, vx, vy)
const pizza = sprites.createProjectileFromSide(img`...`, 0, 70)   // 往下掉
pizza.x = Math.randomRange(12, 148)
pizza.setKind(SpriteKind.Food)

// 从某个精灵身上冒出来：createProjectileFromSprite(图片, 来源, vx, vy)
const bullet = sprites.createProjectileFromSprite(img`...`, ship, 0, -130)  // 往上飞
bullet.setKind(SpriteKind.Projectile)
```

```python
pizza = sprites.create_projectile_from_side(img("""..."""), 0, 70)
bullet = sprites.create_projectile_from_sprite(img("""..."""), ship, 0, -130)
```

- `vx` 横向速度（正数向右、负数向左），`vy` 纵向速度（正数向下、**负数向上**）。
- 投射物由引擎自动移动、自动销毁（飞出屏幕时），但**自己造的普通精灵不会**，见 7.5。
- 动态尺寸图片：`image.create(w, h)` + `.fill(颜色号)` —— `02-flappy-bird` 的柱子就是这么做的。

## 7.3 碰撞：`onOverlap` 是「当…碰到…就…」

```ts
sprites.onOverlap(SpriteKind.Player, SpriteKind.Food, function (sprite, otherSprite) {
    otherSprite.destroy()
    info.changeScoreBy(1)
})
```

```python
def on_catch(sprite, otherSprite):
    otherSprite.destroy()
    info.change_score_by(1)

sprites.on_overlap(SpriteKind.player, SpriteKind.food, on_catch)
```

- 第一个参数是「声明里**写在前面**那类精灵」，第二个是后面那类。
- **靠标签区分规则**：同样是「撞上了」，`Player × Food` 加分，`Player × Enemy` 扣命。
- `03-space-shooter` 两条规则正好相反，是讲这个机制最好的例子。
- ⚠️ 子弹打中敌人时**子弹也要 `destroy()`**，否则一发子弹会穿透打中一串敌人。

## 7.4 分数、生命、结束

| 作用 | TS | Python |
| --- | --- | --- |
| 设分数 | `info.setScore(0)` | `info.set_score(0)` |
| 加分 | `info.changeScoreBy(1)` | `info.change_score_by(1)` |
| 设生命 | `info.setLife(3)` | `info.set_life(3)` |
| 改生命 | `info.changeLifeBy(-1)` | `info.change_life_by(-1)` |
| 结束 | `game.over(false)` | `game.over(False)` |
| 提示弹窗 | `game.splash("标题", "内容")` | `game.splash("标题", "内容")` |

`info` 自带 HUD，不用自己画分数。`game.over(true/false)` 会显示赢/输画面。
`game.splash` **会暂停等按键**，别放进每帧回调。

## 7.5 ⚠️ 回收：飞出屏幕的精灵必须 `destroy()`

投射物引擎会回收，但用 `sprites.create` 造的、或改过速度的精灵不会自动消失。这台机器只有 **96 KiB SRAM**，不回收几分钟就卡死。

```ts
game.onUpdate(function () {
    for (const e of sprites.allOfKind(SpriteKind.Enemy)) {
        if (e.y > scene.screenHeight() + 8) e.destroy()
    }
})
```

```python
def recycle():
    for e in sprites.all_of_kind(SpriteKind.enemy):
        if e.y > 128:
            e.destroy()

game.on_update(recycle)
```

**给孩子讲**：玩具玩完要收进箱子，不然房间会堆满。这是「程序要打扫自己的房间」最好的一课。

## 7.6 音效（别阻塞主循环）

```ts
music.baDing.play()      // 得分
music.pewPew.play()      // 发射
music.powerUp.play()     // 道具
music.wawawawaa.play()   // 失败
```

```python
music.ba_ding.play()
music.pew_pew.play()
```

这些都是**后台播放**的 Playable，安全。
❌ 不要直接 `music.playTone(440, 100)`（会 `pause()` 卡住游戏）；要用：

```ts
music.tonePlayable(440, 100).play(music.PlaybackMode.InBackground)
```

```python
music.tone_playable(440, 100).play(music.PlaybackMode.IN_BACKGROUND)
```

再加个 55 ms 限流，防止爆炸时一帧响几十次。

## 7.7 三个入门游戏的规则表（照着就能自己搭）

| 游戏 | 精灵 | 生成 | 规则 A（好） | 规则 B（坏） | 回收 |
| --- | --- | --- | --- | --- | --- |
| 01 接披萨 | Player + Food | 每 800ms 从顶端随机 x 掉 | Player×Food → +1 分 | 掉出屏 → −1 命 | `Food` |
| 02 小鸟 | Player + Enemy(柱) + Food(隐身得分线) | 每 1500ms 一组 | Player×Food → +1 分 | Player×Enemy → 结束 | — |
| 03 射击 | Player + Projectile + Enemy | A 发子弹 / 每 700ms 出敌人 | Projectile×Enemy → +1 分 | Player×Enemy → −1 命 | `Enemy` |

`02` 最巧妙的是**看不见的得分线**：在柱子缝隙里塞一个 `Invisible` 的 Food 精灵，碰到它就说明成功穿过，不用写「判断 x 超过柱子」的复杂逻辑。

## 7.8 本章最小可运行例子：接住掉下来的方块

**TypeScript**

```ts
const p = sprites.create(img`
    . 2 2 2 .
    . 2 2 2 .
`, SpriteKind.Player)
p.y = 108
p.setStayInScreen(true)
controller.moveSprite(p, 110, 0)
info.setScore(0)
info.setLife(3)

game.onUpdateInterval(700, function () {
    const f = sprites.createProjectileFromSide(img`. 5 .`, 0, 60)
    f.x = Math.randomRange(10, 150)
    f.setKind(SpriteKind.Food)
})
sprites.onOverlap(SpriteKind.Player, SpriteKind.Food, function (a, b) {
    b.destroy(); info.changeScoreBy(1)
})
game.onUpdate(function () {
    for (const f of sprites.allOfKind(SpriteKind.Food)) {
        if (f.y > 128) { f.destroy(); info.changeLifeBy(-1) }
    }
})
```

**静态 Python**

```python
hero = sprites.create(img("""
. 2 2 2 .
. 2 2 2 .
"""), SpriteKind.player)
hero.y = 108
hero.set_stay_in_screen(True)
controller.move_sprite(hero, 110, 0)
info.set_score(0)
info.set_life(3)

def spawn():
    f = sprites.create_projectile_from_side(img(". 5 ."), 0, 60)
    f.x = randint(10, 150)
    f.set_kind(SpriteKind.food)

def on_catch(a, b):
    b.destroy()
    info.change_score_by(1)

def recycle():
    for f in sprites.all_of_kind(SpriteKind.food):
        if f.y > 128:
            f.destroy()
            info.change_life_by(-1)

game.on_update_interval(700, spawn)
sprites.on_overlap(SpriteKind.player, SpriteKind.food, on_catch)
game.on_update(recycle)
```

这就是 `01-catch-the-pizza` 的骨架。让孩子先改 `700`（生成间隔）、`60`（下落速度）、`110`（移动速度）三个数字，再改像素画颜色。
